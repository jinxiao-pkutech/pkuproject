**和你的要求怎么对应**

- **核心可复用：** 核心引擎不依赖 Roslyn，只认统一的中间数据格式；以后接 Java、Python，只需新写一个抽取器。
- **断链：** 8 类断链都有断点位置、原因说明和可以接回去的地方；没有可接回的地方时，返回到断点为止的部分路径。
- **前置路径：** 从员工面待机画面 `SSAW0001` 算到开始画面 A。
- **画面信息：** 输出日文按钮文字、输入约束和错误码。
- **在两台机器上的分工：** 生成代码的机器只用仿真工程跑冒烟测试；真实源码在这台机器上用验收脚本检查，失败结果按 06 文档的 FB 任务流程带回去修。

**这次核实源码后纠正的旧设计书错误**

- `ScreenID` 不是 `Enumeration`，是全局命名空间里的 partial 类。
- 客面画面不是本地跳转显示的，而是员工面发出的 TCP 消息里带 `EventID`、`TargetID`，客面再用反射显示。
- 错误文案在 `StreamingAssets/ErrMsg/ErrMsgType1_Initialize.json`，不在本地化表里。
- 那个按钮的日文实际是 `その他の金額を入力<br>(1,000円単位)`，括号是半角。

- 在生成代码的机器上装好 .NET 8 SDK 和 Python 3.11 以上。任务 T00 会先检查环境，不满足就停下。
