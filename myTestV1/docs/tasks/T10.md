## 实现要点
1. 条件按语法祖先从外到内收集；`else if` 链按 02 §5.7 展开（前面每个 if 记 polarity=false）。
2. 字符串测试识别（主体可以是局部变量、`request.Request["EventPath"]`、成员访问）：02 §5.7 列出的全部形态；`switch` 语句的 `case "x":` 与 switch 表达式的常量模式都算 `switchLabel`；`default` → `switchDefault`（tests 为该 switch 其余全部 label 的 notEquals）。
3. `subject` 用 T09 的 `ValueBuilder` 构建。
4. 方法体含 `goto` 或标签语句 → 该方法内所有条件 `approximate=true`。
5. 可达性：`ControlFlowGraph.Create(...)`；把操作映射到基本块（遍历 `BasicBlock.Operations` 与 `BranchValue` 的子操作），`IsReachable=false` 的块内操作对应的记录 `reachable=false`。lambda 体与局部函数用 `GetAnonymousFunctionControlFlowGraph` / `GetLocalFunctionControlFlowGraph`。
6. CFG 创建异常 → 全部可达 + `I_CFG_UNAVAILABLE` 诊断。
