## 实现要点
1. 控件名与 UXML 交叉核对：在该 View 对应的 UXML（同目录 `../Screen/<View>.uxml` 或按名称全局查找唯一文件）中找到同名元素 → 填 `uxml_path`、`hierarchy_path`；找不到 → 仍记录控件，`uxml_path=null` 并 info 诊断。
2. 处理方法：assign 右值经 `ValueResolver.ResolveConcrete`（字段指向）得到 lambda/methodRef；记录 lambda 本身为 handler（链从 lambda 开始，T18 会继续进入其中的 `eventHandler?.X()` 调用）。
3. 文字键下标绑定的识别条件必须同时满足（02 §9.3-4）；满足 → candidate；任何一项不满足 → 不推断。
4. 约束错误码：属性 Q 的全部赋值都要找；右值形态 `callResult(getter, args).LocalizeMsg`、`callResult(...).Msg`、直接 `callResult(...)`；实参形态 `staticMember(ResultStatusCode.X)`、`memberAccess(staticMember(X), Id)`、`const int`。
5. 同一约束在多个方法中出现 → 多行记录（各自的方法与条件），不合并。
6. 约束所在画面：View 类型 → `screens`。
