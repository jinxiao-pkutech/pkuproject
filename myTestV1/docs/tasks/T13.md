## 实现要点
1. **禁止**引入 YAML 库；行解析器只识别 02 §9.9 列出的键，其他行忽略。
2. 双引号标量的续行：行尾无闭合引号时，后续行去掉前导空白后以单个空格连接（行尾 `\` 表示不插入空格直接连接）；直到出现未转义的 `"`。
3. 无引号标量：后续行缩进比 `m_Localized:` 所在行更深、且不是 `m_Metadata:` 等键 → 以空格连接。
4. UXML：`XmlReaderSettings { DtdProcessing = Prohibit, XmlResolver = null, IgnoreComments = true }`；命名空间前缀元素（`ui:UXML`、`Style`）跳过；`xsi=` 属性不影响解析。
5. 错误文案 JSON：语言字段映射来自配置；`messages.code` = ErrCode。
6. 所有路径用工程相对路径记录。
