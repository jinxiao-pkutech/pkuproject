# T11 构建管线 P1–P5 与 Core 解析服务

## 目标
把抽取器、存储串成可运行的构建管线（P1–P5、P9），实现 Core 的派发与值解析服务（02 §8.1、§8.2），并为后续阶段（P6–P8）预留插槽。

## 前置
T03、T10

## 必读
- `docs/02_架构设计书.md` §2、§3、§7.4、§8.1、§8.2

- `src/ScreenFlow.Core/Pipeline/IndexBuilder.cs`（阶段编排；`IDomainStage` 插槽列表：P6 资源、P7 适配器、P8 画面图；本任务插槽为空列表）

- `tests/ScreenFlow.Core.Tests/Resolution/`、`tests/ScreenFlow.Cli.Tests/IndexBuildTests.cs`

## 实现要点
1. `IndexBuilder.Build(projectRoot, profile, dbPath, configDir, extractorFactory)`：P1/P2/P3 由 `CSharpExtractor` 完成；P4 `IrWriter`；P5 建立派发所需的内存索引（impl 反向表、overrides 闭包）；P9 写 meta（02 §7.4）并原子替换。
2. `Dispatcher` 与 `ValueResolver` 只读数据库（通过 `IndexReader`），可在构建期（P7/P8）与查询期使用。
3. `FieldPointsTo`：按 02 §8.2 的“接收者静态类型相同或存在继承关系”过滤；结果缓存到内存字典。
4. `ResolveContext`：`AllowParamPropagation`、`MaxDepth`、`Visited`（防环）、`Providers`。
5. CLI `index build`：参数 `--project --profile --db --config-dir --parallel`；stdout 只输出一个信封 JSON；异常映射为 02 §11.3 的错误码与退出码。
