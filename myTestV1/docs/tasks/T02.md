# T02 IR 模型、Schema、NDJSON

## 目标
定义语言无关的 IR（02 §5），提供序列化、反序列化、Schema 校验与外部抽取器适配。

## 前置
T00

## 必读
- `docs/02_架构设计书.md` §5（全部）、§1.1

## 产出
- `src/ScreenFlow.Core/Ir/`：`IrRecord`（判别联合：`MetaRec`、`FileRec`、`SymbolRec`、`ImplRec`、`CallsiteRec`、`AssignRec`、`CreationRec`、`CfgRec`、`MarkerRec`、`DiagRec`）、`Value`（02 §5.4 全部 kind）、`Arg`、`TypeRef`、`Condition`、`StringTest`、`Span`
- `src/ScreenFlow.Core/Ir/IrJson.cs`：`Write(IrRecord, Utf8JsonWriter)`、`ReadLine(string) → IrRecord`（`{"k":…, "v":…}`）
- `src/ScreenFlow.Core/Ir/IrValidator.cs`：结构校验（必填字段、枚举值、ID 前缀、Value 嵌套深度 ≤ 6）
- `src/ScreenFlow.Core/Ir/Ids.cs`：02 §5.6 的 ID 计算函数（`SymbolId(profile, assembly, key)`、`SiteId(prefix, callerId, file, spanStart)`、`EvidenceId(file, span)`、`DerivedId(prefix, object)`；derived 用规范化 JSON = 属性名排序、无空白）
- `src/ScreenFlow.Core/Extraction/IFactExtractor.cs`、`ExternalProcessExtractor.cs`
- `schema/ir-1.schema.json`（JSON Schema draft 2020-12，与模型一致）
- `tests/IrEmitterHelper/`（控制台项目，加入 sln）
- `tests/ScreenFlow.Core.Tests/Ir/`

## 实现要点
1. `Value` 用多态 record（`[JsonPolymorphic(TypeDiscriminatorPropertyName = "kind")]`），kind 名与 02 §5.4 完全一致。
2. JSON：camelCase；省略 null；数组不省略。
3. `ExternalProcessExtractor`：参数 = 命令行 + 工作目录；逐行读 stdout，`IrValidator` 校验，非法行 → 抛出 `IrSchemaException`（含行号）；stderr 透传为诊断。
4. 抽取器契约：
   ```csharp
   public interface IFactExtractor
   {
       string ExtractorId { get; }
       string IrVersion { get; }            // 必须等于 "1"
       Task<ExtractionResult> ExtractAsync(ExtractionRequest request, CancellationToken ct);
   }
   public sealed record ExtractionRequest(string ProjectRoot, ProfileConfig Profile, IProgress<ProgressEvent> Progress);
   public sealed record ExtractionResult(IAsyncEnumerable<IrRecord> Records);   // 诊断以 DiagRec 在记录流中输出
   ```
5. 不依赖任何 JSON Schema 库：`schema/ir-1.schema.json` 供外部抽取器作者参考；`IrValidator` 手写校验并在测试中与 schema 的 `required`/`enum` 列表比对（读取 schema 文件提取这些列表）。

## 测试（新增）
- `Ir_RoundTrip_AllRecordKinds`（每种记录、每种 Value kind 各一例：写→读→相等）
- `Ir_Validator_RejectsMissingId`、`Ir_Validator_RejectsDeepValue`
- `Ir_Ids_DeterministicAndPrefixed`（相同输入同 ID；`DerivedId` 对属性顺序不敏感）
- `Ir_Schema_EnumsMatchModel`（schema 中的 kind 枚举 = 模型）
- `Ir_ExternalProcess_ReadsNdjson`：启动测试辅助控制台项目 `tests/IrEmitterHelper`（`dotnet <dll>`），它输出 2 行合法 NDJSON；再用参数让它输出 1 行非法记录，断言抛出 `IrSchemaException` 且含行号。不依赖 Python
