## 实现要点
1. device：命令接口集合由类型集合锚点解析；callsite 目标为这些接口的成员，或为实现类中实现这些接口成员的方法（经 `impls` 反查）→ 边界。返回类型解包 `Task<T>`/`UniTask<T>`；topicTemplate = 实现类 `topicMethods` 方法体中 return 的 Value（`template` 或 `const`）；回流候选 = 实现类的 `callbackMethods` + 全程序以 lambda/methodRef 调用 `receiveEventSetters` 的实参。
2. api：apiKey 按形参名取；`ResolveStrings`；`mockAvailable` 检查 `localMockDir` 下文件名包含 apiKey（大小写不敏感）的文件。
3. native：`objectCreation` 类型 ∈ `javaTypes` → key = 构造第 1 实参；对该实例（local.origin 为该创建）的 `Call/CallStatic/Get/Set` 调用 → key = 类名 + "." + 第 1 实参；DllImport → key = 库名 + "." + 方法名。
4. sql：表名分词规则见 02 §9.8；同一字符串多个表全部记录；写入方 = `tableAccess` 中 mode=write 且含该表的方法。
5. queue：`enqueueMethods` 锚点允许 `type: "*"`；lambda 在 `objectCreation(requestType).args[lambdaArgIndex]`；`deferredInvokers` 按目标方法全名匹配。
6. reflection：排除 `domainHandledReflectionMethods`（`member: "*"` = 该类型全部方法）。
7. entries：02 §9.10；scan 入口额外写一条 ExternalHardware 边界（contract.kind = `deviceInput`，key = `<Presenter>.OnScan`）。
