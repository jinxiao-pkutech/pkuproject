实现 02 §6.4：根据 `AssemblyInput` 构建每个程序集的 `CSharpCompilation`。

## 实现要点
1. 源文件用 `SourceEncoding` 判定的编码读入 `SourceText`；`CSharpSyntaxTree.ParseText(text, parseOptions, path: 工程相对路径)`。
2. 程序集依赖：若 A 的某个引用路径的文件名（去扩展名）等于另一个输入程序集 B 的名称 → A 依赖 B，用 `B.ToMetadataReference()`（CompilationReference）。环 → 诊断并改用文件引用。
3. 引用文件不存在 → 已由 Preflight 报告，此处跳过；`allowHostFrameworkReferences=true` 且没有任何 BCL 引用（无 `mscorlib`/`netstandard`/`System.Runtime`）→ 加入 `AppContext.GetData("TRUSTED_PLATFORM_ASSEMBLIES")` 中的全部 dll。
4. 编译诊断：每个程序集统计 error/warning 数，error 前 200 条写诊断 `E_COMPILE`（severity=warning，因为解析仍可继续），不注入任何类型。
5. 只构建 profile 需要的程序集及其依赖。
