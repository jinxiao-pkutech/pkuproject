## 实现要点
1. UXML 采用 03 §14.3 形态：根元素 `ui:UXML` 带 `xsi=` 非标准属性、`<Style src="project://…&amp;…" />`、元素名为完整类型名、`moneyLabel` 重名。SSAW0903 含 `btnClose`、`selectCharge_1000`、`selectCharge_2000`、`selectCharge_Other`（其中嵌套 `MoneyOtherLabel`）。
2. YAML 采用 03 §15 形态（含 `%YAML`/`%TAG`/`--- !u!114 &11400000` 头），包含 05 §3.3 列出的 5 种标量形态；`m_SharedData.guid` 与共享表 `m_TableCollectionNameGuidString` 一致。
3. 错误文案 JSON：ErrCode 1、2、22、24；22 逐字采用 03 §16。
4. KEY01：一个 `public static class KeyCalculator { public const string Label = "合計金額"; }`，并含日文注释；`make-cp932.py` 把 `KEY01.src.txt` 编码为 CP932 写出。生成后把该文件纳入 T04 的编译测试（去掉临时排除，用 CP932 解码加入编译）。
5. 资源测试只验证“文件存在且格式基本正确”（XML 可加载、JSON 可解析、YAML 文件首行为 `%YAML 1.1`、KEY01 非合法 UTF-8 且 CP932 可解码）。解析逻辑在 T13。
