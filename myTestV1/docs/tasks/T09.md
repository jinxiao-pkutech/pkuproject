## 实现要点
1. `Arg` 按形参对齐：`IArgumentOperation.Parameter`；`ArgumentKind.DefaultValue` 的实参**不输出**；params 数组展开为多个 Arg（同一 paramIndex）。
2. 目标类型 `new()`：`IObjectCreationOperation`（Roslyn 已给出类型）；ValueTuple 创建（`new(typeof(A), typeof(B))` 目标为 `(Type, Type)`）→ `tuple`。
3. 集合初始化器：`IObjectCreationOperation.Initializer` 中的 `IInvocationOperation`（隐式 `Add`）→ `elements` 的一项 = 其实参 Value 列表；字典 `{ k, v }` 同样是 Add(k, v)。对象初始化器的 `ISimpleAssignmentOperation` → `members`。
4. 委托创建：`new KeySeqFunction(model.X.M)` → `methodRef`（methodId = M，receiver = `model.X` 的 Value）；`IDelegateCreationOperation` 包着 lambda → `lambda`。
5. 字符串折叠：`ILiteralOperation`、`IBinaryOperation(Add)`、`INameOfOperation`、`IFieldReferenceOperation` 指向 const 或 `static readonly string`（初始化器可折叠）、`IInterpolatedStringOperation`、`IConditionalOperation`、`string.Empty`、`.ToLower()/.ToUpper()`；组合按 02 §5.4。
6. 局部变量：在方法内收集该局部的全部赋值（声明初始化器 + 简单赋值），按 02 §5.4 合并；`for` 循环变量识别 `i < x.Count` / `i < x.Length` 的 x 为 `loopBound`。
7. `staticMember.path`：`ScreenID.SSAW0907.Id` → `staticMember(SSAW0907, ["Id"])`（`IPropertyReferenceOperation` 的 Instance 是静态字段引用时）。
8. 事件订阅：`IEventAssignmentOperation` → assign（operator `+=`/`-=`，target = `memberAccess(receiver, eventSymbol)`）。
9. 每个元数据符号被引用时调用 `EnsureExternalSymbol`。
10. `callsite.targetIsVirtual`：`IsVirtual || IsAbstract || IsOverride || ContainingType.TypeKind == Interface`，委托 `Invoke` 为 true。
