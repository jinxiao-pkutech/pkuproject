# T19 路径搜索

## 目标
实现 02 §11.5：K 最短路径、平行边展开、部分路径、诊断、前置路径。

## 前置
T18

## 必读
- `docs/02_架构设计书.md` §11.4、§11.5、§10.4（cost）

## 产出
- `src/ScreenFlow.Core/Pathing/ScreenGraph.cs`（从 `screen_edges` 构建折叠图，平行边列表）
- `src/ScreenFlow.Core/Pathing/Dijkstra.cs`、`YenKShortest.cs`（确定性平局规则）
- `src/ScreenFlow.Core/Pathing/PartialPathFinder.cs`
- `src/ScreenFlow.Core/Pathing/PathService.cs`（`Find(from, to, options)`、`Prefix(to, options)`；返回 02 §11.4 的数据结构）
- `tests/ScreenFlow.Core.Tests/Pathing/`

## 实现要点
1. 先在合成的小图上做纯算法单测（不依赖 fixture）：菱形图、平行边、环、不可达。
2. `triggerText`：从 `controls`/`texts` 取该边 `controlId` 的文字（默认 ja；按画面终端的检索顺序；带 `confidence`）；不存在 → `null` 并在 `unresolved` 中列出。
3. 路径的 `breaks`：路径所有边引用的断链去重，按 breakId 排序，取完整记录。
4. `diagnosis` 按 02 §11.5-6 计算。
5. 终端未指定时多组合合并：结果按 cost 排序后取前 K。
