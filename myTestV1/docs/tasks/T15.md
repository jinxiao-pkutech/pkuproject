## 实现要点
1. 发送点：目标方法属于 `tcp.sendMethods`；实参按形参名取。
2. 形参传播：eventPath 或 payload 是 `param` 时，`ValueResolver` 返回每个来源 callsite 的值；每个来源形成独立的 messageSend 记录（`effectiveSites` = 该来源 callsite），记录 ID 由 (发送 callsite, 来源 callsite) 计算。
3. payload：`local.origin` 或直接 `objectCreation(payloadType)`；`EventID`/`TargetID` 来自 `members`；`TargetID` 经 `ScreenIdValueProvider` 折叠为画面 ID。
4. `eventIdKind`：属于 `displayEventIds` → `display`；属于 `closeEventIds` → `close`；以 `commonEventIdPrefix` 开头的其他 → `common`；null → null。
5. 接收方：02 §9.7-2；处理方法 = 实现了名为 `receiverInterfaceMethod` 的接口方法的方法；注册判断 = 该类型任意方法中存在 `receiverRegistrationMethod` 调用且实参为 `this`。
6. EventPath 主体判定：subject 解析（经 `local.origin`）为 `elementAccess`，index 为 `const "EventPath"`（键名来自配置）。
7. 本任务**不**产生断链（断链在 T18 遍历时产生）。
