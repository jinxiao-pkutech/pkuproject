## 实现要点
1. 每个命令：解析参数 → 打开 `<db>`（不存在 → `E_INDEX_NOT_FOUND`）→ 计算 stale → 调用查询 → 输出信封。
2. `screen get` 等在 ID 存在于两个终端且未指定 `--terminal` 时：返回两个结果（数组），不报 `E_AMBIGUOUS`；`symbol find` 同名多个时全部返回。
3. `evidence get`：从 `--project`（或 meta 中记录的工程根，相对于 db 的位置）读取文件，用记录的编码解码；计算片段哈希与 `snippet_hash` 比较，不一致 `meta.stale=true`。
4. 输出中所有路径为工程相对路径；任何绝对路径（含盘符或以 `/` 开头）出现在 data 中 → 测试失败。
5. `index dump`：02 §7.5。
6. `debug stats/callsites/sends`：02 §11.2 末尾新增的 4 个命令。
