## 实现要点
1. 解析宽容：未知选项进入 `IgnoredOptions`，不报错。
2. define 处理：rsp define → 移除 profile.remove → 若 `derived` 则加 profile.add。结果排序去重。
3. Unity 版本推断：define 中 `UNITY_\d{4}_\d+_\d+` 取最长者（如 `UNITY_2022_3_68` → `2022.3.68`），与 `ProjectVersion.txt` 的前三段比较。
4. `I_SOURCE_NOT_IN_RSP` 扫描 `Assets/**/*.cs` 与 `*.CS`（大小写不敏感），路径比较统一为 `/` 与大小写不敏感。
5. 返回 `PreflightResult { Inputs, Diagnostics, Derivation, PlatformDetected, UnityDeclared, UnityCache }`。
6. 没有可用 rsp → `NoCompilationInputException`（CLI 映射为 `E_NO_COMPILATION_INPUT`，消息中提示：用 Unity 2022.3.68f1 打开工程并编译；Android 需执行一次 Player 构建）。
