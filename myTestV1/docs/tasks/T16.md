## 实现要点
1. 登记方法匹配：目标方法名 ∈ `registerMethods.name`，且目标方法的所属类型 = `registerType` 或实现了它（调用通常经 `iKeySeqReg` 字段，类型为接口）。
2. 表实参：`local.origin` → `objectCreation`；`elements` 每项的唯一实参为 `objectCreation(recordType)`。空表合法（0 条）。
3. 执行点：实参 0 为 `objectCreation(KeySeqRequest)` → `members` 中 `PsCode`；或 `local.origin` 同上；其他 → `psCode=null`。
4. 执行目标方法（ExeKeyProc）在遍历中视为 domainHandled：在 `domain_edges.json` 写 `"domainHandled": true`。
5. DI：只在 `locatorType` 及其 partial 声明的方法与 lambda 中查找注册；工厂 lambda 中找 `factoryResolveMethods` 的 `typeArgs[0]`。
6. `DiValueProvider`：`callResult` 目标为 `locatorType.getMethods` 且有 `typeArgs[0]` → 注册的实现类型集合；多个 → `ValueResolution.Ambiguous = true`（T18 据此记 DiAmbiguous 断链）。
7. 注意：`GetService<EValueRwController>()` 这种直接取具体类型的调用，注册为 (T, T) → 唯一。
