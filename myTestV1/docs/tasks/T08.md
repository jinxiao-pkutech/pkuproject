## 实现要点
1. partial 类型：一个 symbol，`declarations` 按 (file, sl) 排序；`file/span` 取第一个声明。
2. 字段/属性 `initializer`：本任务先输出 `unknown` 占位（kind=`unknown`, text=源码），T09 替换为完整 Value 折叠。
3. 元数据符号：被引用时才输出（T09 中由 callsite 等触发）；本任务提供 `EnsureExternalSymbol(ISymbol)` 方法并保证只输出一次。
4. `impl`：对每个源码 class/struct，遍历 `AllInterfaces` 的成员，`FindImplementationForInterfaceMember`，非 null 即输出。
5. 并行：按语法树并行收集；输出前排序（02 §6.9）。
6. 变更标记：只扫描注释 trivia；正则来自配置。
