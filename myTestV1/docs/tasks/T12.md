## 实现要点
1. `AnchorResolver`：只在 `symbols` 表中按 (name, file) / (name, fileGlob) / fqName 查找；`member` 在类型及其源码基类链中按名称找全部成员。解析失败 → `E_ANCHOR_UNRESOLVED`/`E_ANCHOR_AMBIGUOUS` 诊断，并把依赖该锚点的功能名写入 `meta.disabledFeatures`。
2. 画面 ID：字段初始化器 `objectCreation` 的 `args` 按 `paramIndex` 取；`isPopUp` 按 `paramName`。
3. registry 元素：`elements[i] = [key, value]`；value 为 `tuple(items=[typeOf, typeOf])` 或 `objectCreation(ValueTuple…)` 的 args 中的 typeOf。
4. `ScreenIdValueProvider`：处理 `staticMember(ScreenID 字段, ["Id"])` → 画面 ID 字符串；也处理 `memberAccess(param/local 的 ScreenID 值, Id)` 经 ValueResolver 解析到 ScreenID 字段的情况。
5. Navigation：目标方法的 `ContainingType` 为 managerType 或其派生；screen 实参经 `ValueResolver`（允许形参传播）解析到 ScreenID 字段 → 画面 ID 集合；写 `domain_edges(kind="navigate")`。
6. evidence：每条领域事实引用产生它的 callsite/symbol 的 span。
