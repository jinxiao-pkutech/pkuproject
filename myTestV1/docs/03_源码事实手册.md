### 10.3 客面接收（已核实）

`Assets/SceneCustomer/Common/Presenter/Script/Tcp/TcpPresenter.cs`：

```csharp
// 收到报文后，全部放入模型队列（紧急级别）执行
model.ModelQueueing.AddQueue(ElementLevel.Emergency, new ElementRequest(() =>
{
    ...
    if (IsCommonEvent(ReceiveRequestData))                       // 参考行 345
        CommonEventHandler(ReceiveRequestData, eventRequest);
    else

private bool IsCommonEvent(SocketRequestData ReceiveRequestData)  // 参考行 798
{
    string[] evts = (ReceiveRequestData.EventID ?? "").Split(".");
    return evts[0].Equals(TcpConst.EVENTID_COMMON);               // EventID 以 "Common" 开头
}

// CommonEventHandler 中：EventID 为显示类时调用 PopupEventHandler（参考行 587）
private void PopupEventHandler(SocketRequestData ReceiveRequestData, EventRequest eventRequest)  // 参考行 846
{
    string eventId  = ReceiveRequestData.EventID;
    string targetID = ReceiveRequestData.TargetID ?? string.Empty;
    switch (eventId)
    {
        case TcpConst.EVENTID_COMMON_DISPLAY_POPUP:
            ScreenID screenID = (ScreenID)typeof(ScreenID).GetField(targetID).GetValue(null);   // 反射
            screenManagerCL.DisplayTargetPopup(screenID);
            break;
        case TcpConst.EVENTID_COMMON_DISPLAY_POPUP_ABOVE:          → ShowTargetPopup(screenID)
        case TcpConst.EVENTID_COMMON_DISPLAY_POPUP_FIRST_CLOSE_AFTER: → DisplayTargetPopup(screenID, false)
        case TcpConst.EVENTID_COMMON_CLOSE_POPUP:                  → HideCurrentPopup(...)
        case TcpConst.EVENTID_COMMON_CLOSE_POPUP_PREVIOUS:         → HidePreviousPopup()
        case TcpConst.EVENTID_COMMON_GUIDANCE_POPUP:               → GuidanceMessages.ShowPopupMessage(screenID, ...)
        case TcpConst.EVENTID_COMMON_OPEN_FULLSELF_GUIDANCE:       → FullSelfGuidanceMessages.ShowFullSelfPopupMessage(screenID, ...)
    }
    BaseScreen screen = screenManagerCL.GetNoneCommonScreen();
    screen.OnReceiveSocket(eventRequest);                        // 参考行 946–947：显示后再把同一事件交给当前画面
}
```

`CommonEventHandler` 中 `EVENTID_COMMON_DISPLAY` 分支同样用 `typeof(ScreenID).GetField(ReceiveRequestData.TargetID)` 反射取得画面，然后 `DisplayTargetScreen(targetScreenID)`（参考行 512–544，含若干对当前画面的特殊判断）。

**结论（建模规则）**：
- 发送端 `SocketRequestData.EventID ∈ {显示类}` 且 `TargetID` 可折叠为画面 ID → 对端终端显示该画面（**远程显示**）。这是跨终端画面跳转的主要机制。
- 显示之后，同一事件路径交给对端“当前非共通画面”的 `OnReceiveSocket`；通常就是刚显示的那个画面。
- `EventID` 不以 `Common` 开头 → 只交给对端“当前非共通画面”的 `OnReceiveSocket`。
- 反射 `typeof(ScreenID).GetField(targetID)` 由上述建模覆盖，**不作为断链**。
- 接收处理在模型队列中执行（延迟执行）。

### 10.4 员工面接收【部分待本机确认】

        StageNo stgNo = ServiceLocator.GetService<IStageNoStatus>().GetStageNo();

建模规则：
- 业务代码调用 `I*Command` 成员 = **硬件断点**（契约：接口.成员、参数类型、返回类型 `Task<T>` 解包后的 `T`）。

- Topic 是插值字符串，含运行时值 → 记录为模板 `shared-bus-{*}-service-ngp-device-{*}-events`（常量部分保留，非常量部分用 `{*}`；`EVRW_CATEGORY.ToLower()` 若 `EVRW_CATEGORY` 是常量则折叠为小写值）。
- 回流候选：实现类的 `OnMessageReceived`；以及传给 `SetReceiveEvent(...)` 的方法/lambda。
